# Internship Tasks

## 1-Iris Dataset Exploration & Visualization

### Objective

Perform exploratory data analysis on the Iris dataset and visualize relationships between flower species and their characteristics.

### Skills Demonstrated

* Data Loading & Inspection
* Exploratory Data Analysis (EDA)
* Statistical Summary
* Data Visualization
* Correlation Analysis

### Key Findings

* Dataset contains 150 flower samples from three species.
* Petal dimensions are the strongest indicators of species classification.
* Setosa species is clearly separable from the other species.
* Strong positive correlation exists between petal length and petal width.

### Tools Used

* Pandas
* Matplotlib
* Seaborn

## 2- Credit Risk Prediction

### Objective

Develop a machine learning model to predict loan approval outcomes based on applicant information.

### Skills Demonstrated

* Missing Value Handling
* Feature Engineering
* Classification Modeling
* Model Evaluation
* Risk Assessment

### Models Implemented

* Logistic Regression
* Decision Tree Classifier

### Key Insights

* Credit history is the most influential factor in loan approval decisions.
* Applicants with stronger repayment histories receive approvals more frequently.
* Income-to-loan ratio provides better predictive power than income alone.

### Evaluation Metrics

* Accuracy Score
* Confusion Matrix
* Classification Report

## 3- Customer Churn Prediction

### Objective

Identify customers who are at risk of leaving a bank and understand the factors contributing to churn.

### Skills Demonstrated

* Data Preprocessing
* Feature Encoding
* Classification Modeling
* Feature Importance Analysis
* Customer Behavior Analytics

### Models Implemented

* Random Forest Classifier
* Logistic Regression

### Key Insights

* Older customers exhibit higher churn rates.
* Customer inactivity strongly contributes to churn.
* Geographic location impacts customer retention.
* Product ownership patterns influence churn behavior.

### Evaluation Metrics

* Accuracy
* ROC-AUC Score
* Confusion Matrix

## 4- Insurance Claim Amount Prediction

### Objective

Predict medical insurance charges using customer demographic and lifestyle information.

### Skills Demonstrated

* Regression Modeling
* Correlation Analysis
* Feature Engineering
* Predictive Analytics
* Performance Evaluation

### Models Implemented

* Linear Regression
* Random Forest Regressor
* Gradient Boosting Regressor

### Key Insights

* Smoking status has the greatest impact on insurance charges.
* BMI and smoking together significantly increase healthcare costs.
* Ensemble models outperform traditional linear regression methods.

### Evaluation Metrics

* Mean Absolute Error (MAE)
* Root Mean Squared Error (RMSE)
* R² Score
